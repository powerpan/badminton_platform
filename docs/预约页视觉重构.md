# 预约页视觉重构

2026-09-16。按用户确认的方向，先将预约页作为新版样板，保留 Vue、Element Plus 和预约/结算接口。

## 设计依据

设计稿使用内置 Image Gen 生成：[桌面](design/booking-v2/desktop-concept.png)、[手机](design/booking-v2/mobile-concept.png)。提示要求完整预约界面、纯白底、黑色文字、球场绿选中态、扁平日期轨道和时间表、桌面右侧费用清单、手机单场地选时和固定底部操作；禁止多层卡片、营销标语、装饰大图、假指标。手机稿另修正缺漏的 15:00–16:00 时间段。

- 视觉：白色 `#fff`，正文 `#202822`，辅助文字 `#717973`，分隔线 `#e3e7e4`，选中/主操作 `#176447`；无渐变和阴影，控件圆角 4px。
- 字体：沿用中文系统字体；标题 32/26px，正文/控件 14px，辅助文字 12px，场号/时间使用等宽数字特性。费用合计与当前时段是清单的视觉重点。
- 桌面：日期和场地列直接连接时间表；场地信息放在列头，费用清单只用一条竖线分隔。
- 手机：日期横排，场地切换，单场地两列时段；费用详情和备注进入抽屉；底部固定场次、合计和确认操作，保留现有四项导航。
- 图标：沿用 Element Plus 的 Calendar、Refresh、Search、Check、ArrowRight、EditPen；保留现有 BF 标志和导航。

## 文案与功能边界

主文案：场地预订、选好日期，点击连续时段。、我的预订、本次预约、全部场地、刷新、找空闲场次、场地、选择连续时段、可选、已选、不可用、场地费、会员折扣、优惠、可用余额、待支付占用、合计、备注（选填）、确认预约、费用明细、添加备注（选填）、清空。

示意稿中的日期、时段、价格、场地标签、余额均替换为接口数据；不硬编码三块场地或一小时粒度。设计稿可能存在的文字/金额示例不覆盖业务规则。备注沿用 255 字上限；手机详情使用抽屉以完整容纳费用、备注和取消规则。这些是现有功能所需的明确差异。

保留连续选时、推荐、动态日期范围、维护原因、30 秒刷新、过期会员权益、待支付占用、提交前核价及事务校验。首次只实施预约页与其专用组件/样式，不扩展为全站替换。

### 检查结果

- 前端已有 6 项预约纯逻辑测试通过；`vue-tsc` 类型检查和 Vite 生产构建通过；`git diff --check` 通过。
- 内置浏览器检查 1505×1045、768×1024、390×844、320×740。正常场地与 6 场地场景均无整页横向溢出；多场地仅时间表/标签区域横向滚动。
- 验证连续两格合并、切换场地清空选择、桌面筛选后切到手机再返回、日历选择快捷范围外的 9 月 29 日、费用抽屉、备注和键盘焦点。备注聚焦只显示一条边界。
- 6 场地、30 分钟粒度下，18:00–19:00 两格按每小时 120 元计算为 120 元；不是固定一格一小时。
- 推荐结果经过手动刷新后仍保留，选择推荐可同步场地、时间和金额。修复了原 watcher 因规则对象刷新而误清空结果的问题。
- 时段接口返回 503 时显示错误并禁用确认；恢复接口后重试正常。无场地时显示空状态并禁用确认。
- 改价回归：展示两小时 240 元后将夹具价格改为每小时 150 元，首次确认更新为 300 元并提示重新确认，未发起创建订单请求；再次确认携带 `expected_amount_cents: 30000`，待支付提示也显示 300 元。备注随请求保存，选择“稍后支付”后清除选择和备注。

交互验收使用临时 `localhost:5190` 生产构建预览和完全隔离的接口夹具；夹具没有业务 API 转发，没有向现有数据库写入预约或支付。本轮没有修改后端、数据库结构或提交/推送 Git。开发页面 `localhost:5188/courts` 与数据库支持的公告接口在结束时可访问。

### 保留限制

- 本次是预约页样板，不代表首页、商城和后台已采用这套新布局。
- 验收为桌面内置浏览器的响应式视口，未宣称手机实机、Safari 或真实支付端到端验收。
- Element Plus 全量引入导致主 JS 约 1.10 MB，构建仍有体积和依赖 PURE 注释提示；本轮未调整依赖加载方式。
