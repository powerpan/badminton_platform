# BF羽毛球馆管理平台开发文档

本文档目录用于沉淀 BF 羽毛球馆管理平台的需求、设计、接口、测试、部署和开发计划。项目以任务书为基础，采用前后端分离架构：

- 前端：Vue3、Vue Router、Pinia、Axios
- 后端：Python Tornado
- 数据库：MySQL
- 缓存与并发控制：Redis
- 登录认证：JWT

## 推荐阅读顺序

1. 先阅读任务书，明确项目背景和预期成果。
2. 阅读需求规格说明书，确认系统需要实现的功能边界。
3. 阅读系统概要设计说明书，理解前后端、数据库、Redis 的协作方式。
4. 阅读数据库设计说明书和接口设计说明书，作为编码依据。
5. 阅读详细设计与核心流程说明，重点关注预约锁和状态流转。
6. 阅读测试计划、部署运维和开发计划，指导后续联调、上线和验收。

## 编写原则

- 文档内容以当前任务书为依据。
- 优先保证能指导后续编码、测试和答辩说明。
- 技术设计保持简单清晰，避免引入任务书之外的复杂中间件。
- 后续实现如果发生变更，应同步更新对应文档。
