# 第二阶段：BF 产品与视觉实施

日期：2026-09-16。范围为完善计划 B01–B07，不涉及第三阶段的数据模型与资金流程改造。

## 设计依据

使用内置 Image Gen 生成桌面和手机首页概念，作为本轮实施参照；没有要求用户增加审批步骤。实现继续使用 Vue 3 / Element Plus，所有文字、导航、表格和操作均由代码渲染。

- 桌面概念：[home-desktop-concept.png](design/home-desktop-concept.png)，原生 1505×1045。
- 手机概念：[home-mobile-concept.png](design/home-mobile-concept.png)，原生 853×1844；对应约 390×844 CSS 视口。
- 主色 `#006a43`，底色 `#ffffff`，正文 `#1f2521`，分割线 `#e0e7e3`。后台使用浅灰绿底区分工作区域。
- 字体：Inter / PingFang SC / Microsoft YaHei / Arial / 系统无衬线字体。桌面标题 64px，手机 40px，正文和控件按层级使用 14–18px；示意图脚注 10–11px。
- 组件：顶部导航、开放式双栏首页、浅绿色预约提醒条、公告文字列表、独立后台侧栏、表格与抽屉。避免每段内容重复套卡片。
- 图标采用现有 Element Plus 图标；站点标识沿用第一阶段的球场线条并统一为竖向球场标记。
- 首页固定文案：把时间留给 / 下一场好球。；选一块场地，约一场尽兴的球。；预订场地；查看我的预订；营业时间；预约方式；下一场预约；球馆公告；场上见。动态公告、会员状态、营业时间、预约记录取自接口。

## 代码与行为

- 用户端顶部导航与管理员侧栏分离；管理员可通过账户菜单返回用户端。
- 手机四个固定主入口，活动、商城、公告、帮助与退出登录在“更多”中可达。预约确认栏在底部导航上方。
- 首页公开营业时间接口只返回起止时间，不公开个人预约或管理配置。
- 预约摘要接口按当前登录用户查询完整记录：最近未结束的已确认场次、最早到期待支付订单和待支付总数；不从分页结果猜测下一场。
- 首页与“我的预订”共用预约摘要组件；30 秒刷新及页面恢复可见时刷新，卸载时清理计时器。
- 后台按 12 个业务页面拆分，保留原 API 和业务校验；每个模块独立状态、加载和懒加载产物。通用格式化/确认函数集中在 `views/admin/shared.ts`。
- 新增用户、场地、公告、活动、商品使用抽屉；编辑、会员调整、规则、订单详情也使用抽屉，成功提交后关闭新增抽屉。
- 服务健康状态只在管理总览展示。全局重复页眉、GREENBIRD 标识、固定天气和首页开发进度文字移除。
- 原全局样式按预约、账户、商城、后台提取；删除失效侧栏和页眉规则。新产品样式由 `styles/product.css` 负责。
- 演示数据脚本及用法见 [演示环境.md](演示环境.md)。

## 概念与实现对照

| 核对项 | 概念依据 | 实现处理 |
|---|---|---|
| 布局 | 左标题右照片，下方预约条与两列内容 | 保留结构；手机单列顺序一致 |
| 文案 | 核心标题、入口、营业信息、预约与公告 | 保留核心文案；概念中的示例公告不写入现有库；空状态显示真实内容 |
| 字体与层级 | 大标题、克制导航、清晰正文 | 使用系统中文字体，分别检查桌面与手机换行 |
| 颜色 | 白底、深绿主操作、浅绿提醒条 | 统一 Element Plus 主色及禁用/浅色状态，去掉原有蓝色残留 |
| 图片 | 无蒙版、独立场馆照片区域 | 独立生成相同构图资产；增添示意图标注，避免误认实拍 |
| 图标 | 球场标记、日历、活动、球友图标 | 使用现有图标集，球友入口用对话图标表达动态交流 |
| 响应式 | 手机四入口及更多菜单 | 预约确认栏与底部导航互不遮挡；后台手机采用导航抽屉 |
| 预约页 | 以选择场地、时段为主要操作 | 将重复大图片卡片收敛为编号与资料选择器，使时段表更早出现 |

有意差异：真实公告/空状态替代概念样例；访客显示登录入口；示意图标注；保留可操作状态、金额与错误提示；采用仓库现有组件图标而非复制生成图的手绘线条。概念原生画布尺寸并非请求中的整数 CSS 尺寸，因此同时检查实际桌面和手机视口。

最终对照在同一检查轮中使用 `view_image` 打开两张概念图与最新真实页面截图。桌面按概念原生 1505×1045 截取；手机按 390×844 CSS 视口检查，概念 853×1844 作为同纵横比的高分辨率参照，不将 853px 误当手机 CSS 宽度。

修正记录：品牌图标缓存导致旧标记残留，加入资源版本；商城搜索栏和商品列表宽度不一致，改为同宽；商品图灰底边缘统一为白底；手机后台筛选框因百分比宽度收缩至仅剩箭头，恢复可读的 160px 宽度；手机首页压缩间距、收起空预约的重复辅助句，使公告标题进入首屏；预约详情会员等级改为中文。

首屏文案差异核对：标题、主导航、预订按钮、营业时间/预约方式、预约条及栏目名与设计一致。保留实际业务必需的账户名、空状态、错误重试及图片示意标注；两条“场上见”介绍采用实现文案，并未编造现有活动。手机“查看我的预订”收为“我的预订”，空预约只显示一句状态。字体采用现有系统字体、导航为实际界面的 15px，不复制生成图中的栅格文字；图标保留 Element Plus 线条风格。已按这些明确差异完成设计核对，没有剩余的内容遮挡、失效主操作或整页横向溢出。
